# LiveTrans 用户手册

## 安装

从 [Releases](https://github.com/MisterRabbit0w0/live-trans/releases) 下载：

- **安装版**：`LiveTrans-Setup-x.y.z.exe`（NSIS，带开始菜单与卸载）。
- **便携版**：`LiveTrans-Portable-x.y.z.zip`，解压即用，不写注册表。

首次启动会下载所选 ASR 模型（约几百 MB），请保持网络畅通。

## 四种模式怎么选

| 场景 | 推荐模式 |
|---|---|
| 看外语直播 / 生肉视频 | 模式 2（仅实时翻译）：零磁盘垃圾 |
| 跨国会议，边听边留档 | 模式 1（边翻译边记录） |
| 会议速记，不想花 Token | 模式 3（仅语音记录）：0 外部调用 |
| 只想看原文听写字幕 | 模式 4（纯原文字幕） |

模式可在运行中一键热切，无需重启识别引擎。

## 翻译设置

在主窗口「翻译」页配置 OpenAI 兼容接口：

- **本地 Ollama**：`base_url` 填 `http://localhost:11434/v1`，`api_key` 任意，`model` 填本地模型名。全离线，0 费用。
- **云端**：填服务商的 base_url / key / 模型名（如 DeepSeek、GPT、Gemini 等兼容接口）。

目标语言在下拉框选择；识别语言一般选「自动」即可。

> 小提示：翻译带有**上下文记忆**——最近 3 句的译文会作为上下文，帮助模型处理代词指代和术语一致；被 VAD 切碎的半截句子也会更通顺。

## 字幕浮层

- 拖动：按住浮层空白处拖到任意位置。
- 置顶与穿透：默认置顶；开启「点击穿透」后鼠标事件透过字幕，不影响下层操作。
- 外观：在「字幕样式」里调字号、双语开关、同屏行数、背景不透明度。

## 记录与 AI 纪要

「记录与纪要」工作台按时间戳列出双语对照记录，支持：

- 一键复制 / 导出 Markdown 文件；
- **AI 纪要**：选「完整会议纪要」或「极简速览（<200字）」，复用你配置的翻译模型接口生成；
- 纪要包含：主题与核心主旨、多议题重点、关键结论、Action Items。

## 故障排查

| 现象 | 先查 |
|---|---|
| 没有字幕出来 | 音频源是否选对（系统环回 vs 指定进程）；音量是否过小（<-60 dBFS 会被 AGC 视为静音） |
| 字幕延迟很高 | 换小一点的 ASR 模型；翻译接口换延迟低的 |
| 翻译牛头不对马嘴 | 检查目标语言设置；换更强的翻译模型 |
| 程序无响应 | 看托盘图标状态；导出日志提 Issue |

## 隐私说明

音频捕获、VAD 分句、语音识别全部在本地完成。只有**文本**会发送到你配置的翻译 / 纪要模型接口；模式 3（仅语音记录）全程 0 外部调用。

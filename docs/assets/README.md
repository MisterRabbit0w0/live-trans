# README 截图与演示素材

README.md / README_EN.md 里预留了以下位置（目前是 HTML 注释）。素材就位后，把对应注释换成图片引用即可，中英两份 README 共用同一组文件。

| 文件 | 内容 | 建议规格 |
|---|---|---|
| `overlay.png` | 字幕浮层叠在视频或直播画面上的效果（头图） | 1600×900 左右，PNG |
| `main-window.png` | 控制中心「概览」页 | 原始窗口尺寸，PNG |
| `records.png` | 「记录与纪要」工作台，含一段纪要 | 原始窗口尺寸，PNG |
| `quickstart.gif` | 从启动到字幕出现的全过程 | ≤ 15 秒，≤ 5 MB |

替换示例：

```markdown
![字幕浮层](docs/assets/overlay.png)
```

截图前请确认画面里没有个人信息、密钥、私有会议内容或受版权保护的画面。

# LiveTrans 产品介绍

**LiveTrans** 是一款桌面应用：实时把外语直播、视频、网课和线上会议的语音，转成**双语悬浮字幕**，并能一键生成 **AI 会议纪要**。

看不懂的外语直播、听不清的跨国会议、生肉视频——打开 LiveTrans，字幕直接浮在画面上。

---

## 能做什么

- **实时双语字幕**：系统音频捕获 → 语音识别 → 翻译，悬浮窗置顶显示，可点击穿透，不挡操作。
- **四种运行模式**（运行中一键热切，无需重启）：
  1. 边翻译边记录 —— 实时字幕 + 本地存盘对照；
  2. 仅实时翻译 —— 看直播/生肉，零磁盘垃圾；
  3. 仅语音记录 —— 会议速记，0 外部 API 调用、0 Token 消耗；
  4. 纯原文字幕 —— 高灵敏度实时听写。
- **AI 会议纪要**：一键提炼主题主旨、讨论要点、关键结论与待办项；支持完整版与 <200 字极简版；可导出 Markdown。
- **本地优先，隐私友好**：语音识别在本地运行（faster-whisper），音频不出本机；只有翻译与纪要走你自己配置的模型接口。

## 运行环境

- **Windows 10/11 x64**：正式发行（NSIS 安装器 / 便携 ZIP）。
- macOS / Linux：音频捕获后端已有源码实现，实验性支持，暂未完整验收。

## 快速上手

1. 下载安装包并安装（见 [构建与发布](releasing.md)）。
2. 打开主控制中心，选择运行模式。
3. 在「声音 / 识别 / 翻译」设置里选好 ASR 模型与翻译接口。
4. 点启动，字幕浮层出现；可拖位置、调字号、设透明度。
5. 会议结束后来「记录与纪要」工作台，一键生成纪要并导出。

详细步骤见 [用户手册](user-guide.md)。

## 常见问题

**延迟大概多少？**
语音 → 字幕通常在 2–5 秒，取决于 ASR 模型大小与翻译接口速度。本地模型越大越准、越慢；翻译接口建议选延迟低的。

**支持哪些语言？**
识别语言取决于所选 ASR 模型（whisper 系支持 90+ 语言）；翻译目标语言在设置中选择，常用语言均已覆盖。

**要联网吗？**
本地识别不需要联网。翻译与 AI 纪要需要你配置的模型接口（可配本地 Ollama，即全离线）。

**会上传我的音频吗？**
不会。音频捕获与识别都在本机完成；只有文本会发往你配置的翻译/纪要接口。

**和浏览器插件字幕有什么区别？**
LiveTrans 捕获的是系统级音频，任何软件的声音都能翻——直播客户端、会议软件、视频播放器，不挑来源。
